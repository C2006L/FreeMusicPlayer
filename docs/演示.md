# FreeMusicPlayer 界面与功能说明

当前版本采用深炭灰背景和暖珊瑚色强调色，围绕桌面音乐播放器重新组织界面。仓库中的截图可能随功能迭代略有变化，请以实际运行页面为准。

## 用户端

- 推荐页使用真实在线结果，不用静态假歌曲填充。
- 曲库和搜索合并本地数据库与在线多平台结果，并标注来源及受限状态。
- 歌曲列表支持单击选中、双击播放、收藏、下载和当前播放提示。
- 底部播放器提供切歌、进度拖动、音量、播放模式和队列。
- 播放详情展示封面、唱片动效和同步歌词；数据库歌曲保留站内评论。
- 音频失败或检测到约 30 秒试听时，会按歌名、主要歌手和时长严格换源。
- 配置 DashScope API Key 后，可使用结合数据库曲库的 AI 音乐助手。

## 管理端

管理端用于维护用户、歌手、歌曲、歌单、媒体附件和反馈。在线搜索不会自动污染数据库；只有收藏等需要持久关系的操作才登记在线歌曲。

## 媒体状态

- `完整/未知`：平台未标记受限，仍以实际播放结果为准。
- `可能需会员`：上游返回 VIP 标记，当前账号未必具有整曲权限。
- `试听`：实际媒体约 30 秒且明显短于标称时长。
- `暂不可播`：平台或探测接口确认资源不可用。

项目不会把试听片段描述为完整歌曲，也不会绕过平台付费或账号权限。
