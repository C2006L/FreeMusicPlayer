# FreeMusicPlayer 部署指南

## Windows 本地开发

需要 Windows 10/11、Docker Desktop、JDK 17+、Node.js 18+ 和 PowerShell。项目位于 D 盘时，依赖缓存及服务数据都会保存在项目的 `.runtime` 目录。

```powershell
.\scripts\setup-dev.ps1
.\scripts\start-dev.ps1
```

停止且保留数据：

```powershell
.\scripts\stop-dev.ps1
```

| 服务 | 地址 |
| --- | --- |
| 用户端 | http://localhost:8090 |
| 管理端 | http://localhost:8089 |
| Spring Boot API | http://localhost:8080 |
| Provider | http://localhost:3001 |
| go-music-api Swagger | http://localhost:3002/swagger/index.html |

默认启动 MySQL、Redis 和 go-music-api。MinIO 不是在线播放依赖，只在测试头像、附件或用户上传媒体时启用：

```powershell
.\scripts\start-dev.ps1 -WithMinio
```

## 服务结构

```text
Vue :8090
  -> Spring Boot :8080
       -> MySQL :13306
       -> Redis :6379
       -> Provider :3001
            -> go-music-api :3002（主引擎）
            -> Meting（回退）
       -> MinIO :9000（可选附件）
```

`go-music-api` 作为独立 AGPL-3.0 容器运行，本仓库通过 REST 调用它，不包含其源码。

## 平台 Cookie

需要使用本人账号已有权限时，编辑被 Git 忽略的 `.runtime/go-music-api/cookies.json`：

```json
{
  "netease": "MUSIC_U=...; __csrf=...;",
  "qq": "qm_keyst=...; uin=...;",
  "kugou": "token=...; userid=...;",
  "bilibili": "SESSDATA=...;"
}
```

保存后重启。Cookie 只能赋予账号原本拥有的权限，不能解锁未购买内容。不要提交、截图或共享该文件。

## 数据库升级

新数据库自动执行基础 SQL 和 `sql/migrations` 中的在线曲库迁移。已有数据库不会重新运行 Docker 初始化脚本，需要手动执行尚未应用的迁移，尤其是 `20261022_provider_metadata.sql`。

## 修改后端后的重建

```powershell
.\scripts\stop-dev.ps1
.\scripts\setup-dev.ps1 -SkipDockerPull
.\scripts\start-dev.ps1
```

## AI 助手

```powershell
$env:DASHSCOPE_API_KEY = "你的 API Key"
.\scripts\start-dev.ps1
```

未配置时普通播放功能可用，健康检查会显示 AI 为 `NOT_CONFIGURED`。

## 常见问题

### 只能播放约 30 秒

这是上游提供的试听媒体。播放器会尝试严格匹配的其他来源；全部受限时显示试听提示。自己的有效 Cookie 可能获得账号本来具备的整曲权限，但项目不会绕过 VIP 校验。

### 搜索结果较少

检查 `http://localhost:3002/swagger/index.html` 和 `http://localhost:3001/health`。增强服务不可用时会回退到 Meting，来源会减少。

### 网络连接失败

```powershell
docker compose -f compose.dev.yml ps
Get-Content .runtime\logs\backend.err.log -Tail 100
Get-Content .runtime\logs\provider.err.log -Tail 100
```

### 8080 被占用

脚本已经运行后端时，不要从 IDEA 再启动同一应用。先运行停止脚本，再选择一种启动方式。

### Docker Volumes 显示 0 Bytes

本项目使用 `.runtime` 绑定挂载，不依赖 Docker 命名卷。0 Bytes 匿名卷不代表 MySQL 或 Redis 数据丢失。
