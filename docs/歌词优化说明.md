# 歌词获取、显示与翻译

修改日期：2026-10-29。保留现有音频播放、队列、收藏接口。

## 根因与处理

对用户截图中的歌曲按真实平台 ID 检查发现：GoMusicAPI 返回 `[开始]文字[结束]`，同一开始时间混排日文、罗马音和中文译文。旧解析器将结束时间也展开为演唱时间，造成重复；旧适配器固定清空翻译字段，前端只精确匹配两位小数时间。

- Provider 优先同一平台、同一歌曲 ID 的 Meting 分离歌词，无可用内容时尝试 GoMusicAPI。保留 lyric、tlyric、romalrc、source，不跨 ID 猜测。
- 歌词缓存按完整请求身份及版本元数据区分：有效内容 10 分钟、空结果 15 秒，失败不缓存；最多 300 项，合并相同在途请求，最多 32 个在途请求。
- 前端 LyricDocument 每句保留原文、可选结束时间、译文、罗马音及逐字时间。兼容旧字符串接口。
- 区分句末时间与多个前置时间；去掉同时间、同文字的重复，保留后来再次演唱的副歌。明确同时间的日/韩原文、罗马音和中文归为一行；含糊多声部不强行删除。
- 译文/罗马音按最多 350ms 邻近时间、先后顺序、一次性消费对齐，不按数组下标强配。
- 支持普通/增强 LRC 及明确 YRC 区间。新增“逐字”开关，只在文字覆盖完整、时间连续有序且区间有效时显示逐字高亮；没有可靠逐字时间的行自动使用逐句高亮。沿用音频引擎的 currentTime，不推测音节或伪造时间。无时间轴时显示“非同步歌词”，不提供跳转。
- 支持 LRC 文件 offset 和独立的用户“歌词延后”设置，正数表示延后显示。

## 界面使用

- 译文默认显示、罗马音默认关闭，提供独立开关；长句换行，无歌词横向滚动。
- 手动滚动、触摸或键盘浏览会暂停跟随，点击“回到当前句”恢复。同步行可点击跳转。
- 区分加载中、音源未提供、请求失败及非同步文本，支持重新获取。获取失败时保留已有内容。
- “查找其他来源”复用现有在线搜索，只展示歌名、歌手、版本标记及已知时长匹配的最多 6 个候选，由用户选择；只更换歌词，不切换音频。这不是声纹验证，仍可能没有结果。
- B 站合集不按整条长标题自动套用歌词，应定位具体分 P 或导入文件；元数据不足时无法提供可靠跨源候选。
- 导入不超过 256KB 的 LRC/TXT，支持 UTF-8/GB18030。覆盖前确认，仅保存于当前浏览器 IndexedDB，不上传文件。
- 浏览器最多保留 200 份歌词文档，优先淘汰普通缓存，再淘汰最旧导入。普通缓存 24 小时后重新获取，导入内容不按时间过期。此存储有上限，不应视为永久备份；清理浏览器数据会丢失，也不跨账号设备同步。
- 切歌取消旧请求和翻译轮询，并校验结果版本。歌曲详情也校验旧响应，避免旧歌歌词覆盖新歌。
- 保留空白时间标记作为结束边界，间奏期间清除上一句高亮；同步定位改为二分查找。
- 偏移调整不再刷新普通缓存的获取时间；新增解析版本标记用于普通缓存失效。更新失败时可继续显示旧缓存；已导入内容和已有机器翻译不会因解析版本变化被直接丢弃。
- 自动跟随在下一帧滚动前再次检查手动浏览状态；窗口大小和辅助文字开关变化时重新定位当前句，尊重系统减少动画设置。

## 本机机器翻译

主动点击“补充中文翻译”后，缺失译文的原文才会发送到配置的 Ollama。使用 OLLAMA_BASE_URL / OLLAMA_MODEL，默认 qwen2.5:3b。原文和播放无需等待翻译。

接口：POST /agent/lyrics/translations 创建；GET /agent/lyrics/translations/{id} 查询；DELETE 同路径取消。

- 每次 1–200 行、每行最多 500 字、总计 20000 字，按 12 行分批。
- 2 个工作线程、4 个排队任务，同一用户/匿名 Session 最多 1 个活动任务，创建接口使用现有 IP 限流。
- 任务由登录用户或匿名 Session 隔离。其他身份不能读取或取消。
- 校验每批 ID 完整唯一、译文类型和长度；缺行、重复或异常输出视为失败。时间轴和原文不交给模型修改。
- 全部成功后才补充缺失译文，不覆盖音源已有译文，标注“含 Ollama 机器翻译”。结构校验不保证语义准确。
- 单批 75 秒超时，每批开始检查 4 分钟预算（最后一批可能跨过预算）；客户端最多等 5 分钟，可取消，失败可重试。
- 服务端按身份、模型和原文摘要复用结果，最多 128 份任务记录，保存 30 分钟，进程重启后清空；浏览器另外保存完成文档。
- Ollama 未启动、缺模型或输出异常会明确失败。本次真实完成一条英文句子的中文翻译，不据此承诺整首日文翻译质量。
- 停止时如果创建响应尚未到达，会显示“正在停止翻译”，取得旧任务 ID 并处理取消后才允许重试，避免旧请求取消新任务。已完成任务不再发送取消请求；取消失败会提示。服务端已经处理但客户端始终未收到 ID 的网络故障仍依靠服务端超时收敛。
- 轮询请求同时受会话取消信号和单次网络超时限制，防止连接挂起时无限等待。

- 后端完整构建测试通过：common 5、server 22，包括模型 HTTP 夹具的 ID 校验、复用、身份隔离和取消。
- Provider 20 项、前端 25 项测试通过；前端类型检查及生产构建通过。本轮精修仅修改前端，沿用上一轮后端/Provider 验证记录。
- 浏览器回归覆盖生成 WAV 的真实播放/拖动、歌词分组、罗马音、导入、翻译、偏移、窄窗口、刷新后保留导入与翻译、重新获取失败时保留已有内容，以及工作区和助手。
- 截图歌曲真实 API/页面检查得到 34 个原文条目、33 条中文译文；桌面和 560px 窄窗口无歌词横向溢出、无未捕获页面异常。这不是整曲音频可播放的证明。
- 本轮新增回归覆盖间奏结束边界、逐字时间有效性、逐字显示和真实跳转、偏移不延长缓存、创建响应延迟时取消后立即重试、完成后不再取消。

测试数据仅用于自动化，不进入产品曲库。歌词/译文覆盖率与时间轴质量仍依赖上游；没有引入自动语音识别、假歌词或假时间轴。
