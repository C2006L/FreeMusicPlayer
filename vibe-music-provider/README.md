# FreeMusicPlayer Provider

FreeMusicPlayer 的统一音源适配侧车。它优先调用独立的 `go-music-api` 服务获取扩展平台搜索、源元数据和媒体代理能力，并以 [Meting](https://github.com/metowolf/Meting) 作为兼容回退。

本服务不会按“歌名 + 歌手”删除跨平台结果，也不会在搜索阶段隐藏所有暂时解析失败的条目。链接探测只证明可访问，不证明完整播放；未知资源保持 `unknown`，不能因非 VIP 或 Range 请求成功就标成 `full`。浏览器根据实际时长和播放覆盖范围提供独立、短期有效的验证记录，详见主 README。

```bash
npm install
npm start
```

默认只监听 `127.0.0.1:3001`。可通过 `HOST` 和 `PORT` 修改。设置 `GO_MUSIC_API_URL=http://127.0.0.1:3002` 即可启用增强引擎；未设置或服务不可用时自动回退到 Meting。

Windows `start-dev.ps1` 现在通过 `supervise.mjs` 启动工作进程；异常退出时记录退出码并在1–30秒内尝试重新启动。`provider.pid` 是监护进程，`provider-child.pid` 是实际工作进程，停止脚本会分别核验并关闭。监护进程本身被关闭或电脑重启后仍需重新运行启动脚本，不是系统开机服务。

搜索返回成功且 `songs:null` 时按空结果处理，不再误报平台故障。真实连接、协议和请求错误仍标为检索失败。搜索排序优先精确歌手、歌名和组合词匹配，不把标题提到某歌手的视频直接排在该歌手歌曲前面；标称时长仅作为元数据完整度的轻微排序因素，不证明完整可播。

主要接口：`/health`、`/search`、`/discover`、`/stream`、`/cover`、`/lyric`、`/playlist?source=netease&id=…`、`/bilibili/collection?bvid=BV...`、内部诊断 `/metrics`。`sourceExtra` 是不透明的上游元数据，只用于后续流解析，不应由前端修改。

搜索引擎逻辑调用限制为6个并发、60个等待；排队最多5秒。相同进行中请求合并，正结果缓存30秒，正常空结果4秒；全部音源失败不缓存成正常空结果。单引擎连续异常3次后冷却30秒。Meting 自身不支持取消底层请求，超时只释放逻辑调用，不表示底层网络连接已经取消。

Go 引擎封面通过受控代理读取：限制图片类型与5MB大小，校验解析后的公开IP、固定连接DNS结果、重定向逐跳复查，拒绝私网和本机地址。侧车保持仅本机 / 容器内访问，浏览器通过 Java API 访问；不要把诊断端口作为公网接口开放。搜索与普通请求日志带请求编号，不记录请求查询串或账号凭据。

B 站目录接口通过增强服务的原链接解析能力取得真实分 P / 合集条目，保留源站目录顺序与每条独立的 `BV|CID`，不使用普通搜索的 50 条上限，不按标题拆曲。最多缓存 32 个目录、每个 5 分钟；超过 1000 条明确失败，避免伪装成完整结果。失效、私有或受限的视频仍受上游访问权限限制。

`/discover` 使用增强服务的 `/api/v1/playlist/recommend` 与 `/api/v1/playlist/detail`，读取网易云/QQ 的真实推荐歌单曲目，按平台交错排列并去重。缓存 10 分钟、按批轮换；部分来源失败时保留成功结果。不再用“热门歌曲”关键词搜索生成伪榜单，也不把歌单收录或链接可访问等同于完整可播放。

搜索结果会检查每个关键词是否命中歌曲名、歌手或专辑，过滤上游返回的无关填充结果。`node --test *.test.mjs` 验证相关性过滤；未找到匹配结果时不使用其他歌曲冒充。当前接入的 API 没有独立歌手接口，前端按歌曲贡献者字段展示相关歌手，不提供虚构头像或全量作品计数。

## 自有账号授权（可选）

如果你本人拥有对应平台账号，可以在启动 Provider 前通过环境变量提供自己的 Cookie：

- `MUSIC_COOKIE_NETEASE`
- `MUSIC_COOKIE_TENCENT`
- `MUSIC_COOKIE_KUGOU`
- `MUSIC_COOKIE_KUWO`
- `MUSIC_COOKIE_BAIDU`

Cookie 只由本机 Provider 读取，不会返回给浏览器，也不应提交到 Git。配置授权只能使用账号本身已有的播放权益；没有权限的歌曲仍会标记为试听或不可用。

第三方平台的可播放性取决于版权、地区、登录状态和上游接口，请只播放你有权访问的内容，并遵守平台服务条款。
